Oasis Infobytes Data Science Internship Portfolio
This repository contains the machine learning and data science projects completed as part of my internship at Oasis Infobytes. The internship focused on solving real-world classification and regression problems using Python and popular data science libraries.

Projects Included
Iris Flower Classification

Description: Developed a supervised classification model to identify Iris flower species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.

Key Tasks: Exploratory Data Analysis (EDA) with pairplots, data preprocessing, stratified train-test splitting, and training a Logistic Regression model evaluated via accuracy scores and confusion matrices.

Email Spam Detection

Description: Built a Natural Language Processing (NLP) pipeline to classify email messages as either Spam or Ham (not spam).

Key Tasks: Text cleaning via regular expressions, tokenization, stop-word removal, and stemming using NLTK, feature extraction with CountVectorizer, and training a Multinomial Naive Bayes classifier saved via pickle for live inference.

Fraud Detection

Description: Implemented a machine learning model to detect fraudulent transactions or patterns from structured datasets.

Key Tasks: Data cleaning, handling class distributions, feature engineering, and evaluating model performance using classification metrics.
